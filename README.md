# 📚 StudySphere AI

StudySphere AI is an AI-powered learning companion developed as part of the **ShadowFox AI Engineer Internship**.

## 🚀 Project Overview

StudySphere AI is designed to help students improve their learning experience through a simple and interactive web application. It provides tools for studying concepts, practicing quizzes, revising important topics, and planning study sessions.

## ✨ Features

- 📚 **Study Workspace** – Get structured explanations for study topics.
- ⚡ **Quiz** – Practice concepts through interactive questions.
- 🔄 **Revision** – Generate quick revision notes for important topics.
- 🗓️ **Study Planner** – Organize study sessions based on subject, date, duration, and priority.
- 🤖 **AI Assistance** – Supports AI-powered educational explanations using the Google Gemini API when configured.
- 🎨 **Interactive Interface** – Simple Streamlit-based learning interface.

## 🛠️ Technologies Used

- Python
- Streamlit
- Google Gemini API
- Google Gen AI SDK
- GitHub
